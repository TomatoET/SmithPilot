# Code of Conduct

## Our Standards

Project participation must remain respectful, technical, and constructive.
Examples of acceptable behavior include giving actionable feedback, respecting
different experience levels, and focusing disagreement on code and evidence.

Harassment, discrimination, threats, publishing another person's private
information, and sustained disruptive behavior are not acceptable.

## Enforcement

Report conduct concerns privately to the repository owner through GitHub. The
maintainer may edit or remove contributions and may temporarily or permanently
restrict participation when necessary. Reports will be handled as privately as
practical.

This policy applies in repository discussions and in public spaces when a
participant is representing the project.
